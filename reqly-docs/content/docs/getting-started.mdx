Reqly runs entirely in the browser — no installation or account required to send your first request.

## The interface

The main interface is split into three areas:

1. **Sidebar** — navigation across requests, collections, history, dashboard, and settings.
2. **Request Panel** — the top section where you build a request (URL, method, headers, body).
3. **Response Panel** — the bottom section that shows the response: status, timing, headers, cookies, and body.

<Callout>
  The **Request Panel** and **Response Panel** are resizable — drag the divider between them to fit your workflow.
</Callout>

## Send your first request

<Steps>
  <Step>
    **Pick a method.** The default is `GET`. Click it to choose `POST`, `PUT`, `PATCH`, `DELETE` or more.
  </Step>
  <Step>
    **Enter a URL.** Type a full URL such as `https://api.example.com/users`.
  </Step>
  <Step>
    **Press Send.** The response panel updates with the status code, headers, and body.
  </Step>
</Steps>

That's it. Your request is automatically saved to [Request history](/docs/history).

## Try it with a real API

Here is a request you can run immediately against the JSONPlaceholder API:

```http title="GET https://jsonplaceholder.typicode.com/posts/1"
GET https://jsonplaceholder.typicode.com/posts/1
```

Expect a `200 OK` response with a JSON body containing a sample post.
