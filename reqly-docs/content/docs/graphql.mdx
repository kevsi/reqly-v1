Reqly includes a dedicated GraphQL interface with a query builder, variables editor, and response viewer.

## Sending a GraphQL query

1. Switch to a GraphQL request.
2. Enter your GraphQL endpoint in the URL bar.
3. Write your query in the query editor, with optional **variables** and **operation name**.
4. Send — the response appears in the response panel, formatted as JSON.

## Features

- **Query editor** — syntax-highlighted GraphQL with validation
- **Variables** — define GraphQL variables used by your query
- **Schema exploration** — browse the endpoint schema to discover types and fields
- **Response viewer** — pretty-printed JSON responses with syntax highlighting
