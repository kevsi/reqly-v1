Reqly is a full-featured API client built for developers. It lets you send HTTP requests, inspect responses, organize your work into collections, manage environment variables, and automate your API tests — all from your browser.

## What Reqly can do

- **HTTP requests** — full control over method, URL, headers, query params and body.
- **Response inspection** — status code, timing, size, headers, cookies, and pretty-printed bodies.
- **Scripted tests** — JavaScript assertions that run before and after each request.
- **GraphQL** — query builder, variables, and schema exploration.
- **AI-powered workflows** — follow-up request generation from responses.
- **Bulk automation** — run entire collections with progress tracking.
- **Workspaces & sync** — save your setup as a project, or sync across devices.
- **Format interop** — import/export OpenAPI 3.0, Postman, and Bruno collections.
