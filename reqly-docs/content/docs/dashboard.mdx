The **Dashboard** gives you an overview of your API usage and activity.

## What you'll see

- **Total requests** — the count of all requests you've sent
- **Recent activity** — requests broken down by day / week
- **Success rate** — the ratio of `2xx` responses against `4xx` / `5xx`
