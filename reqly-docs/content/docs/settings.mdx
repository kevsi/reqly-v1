The **Settings** page centralizes Reqly's configuration.

## Appearance

Choose between **Light**, **Dark**, and **System** theme modes. Reqly also ships several accent themes you can switch between from the theme picker.

## Language

The interface is available in multiple languages — currently English and French.

## AI Configuration

Configure your AI provider with an API key for follow-up request generation:

- **Provider** — OpenAI, Anthropic, or a custom OpenAI-compatible endpoint
- **API key** — stored securely
- **Model** — select the model to use

See [AI assistant](/docs/ai) for how AI is used.

## Data management

- **Clear request history** — wipe all saved history
- **Manage saved projects** — view and delete saved project files
- **Export / import** — move your workspace data in and out of Reqly

## Keyboard shortcuts

From Settings you can also review the available keyboard shortcuts. Press `Ctrl`/`Cmd` + `K` anywhere to open the shortcuts modal.
