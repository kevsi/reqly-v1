Reqly lets you treat a group of requests, collections, and environments as a single **workspace**, export it as a file, and restore it later.

## Save as project

Use **Save as Project** to export your entire workspace — requests, collections, and environments — into a JSON file.

## My Projects

Reopen a saved project from the **My Projects** page to restore your entire setup on any machine.

## Workspaces

The **Workspaces** page lets you manage multiple standalone workspaces. This is useful when you work across different products, teams, or environments and want to keep their requests, collections, and variable sets separate.

Each workspace contains its own:

- Requests and tabs
- Collections
- Environments and variables
- Request history (in shared mode)

## Cloud sync

In the hosted web version, workspaces can sync with the Reqly cloud backend so your work follows you across browsers or teams. Sharing and sync require sign-in to the hosted service.

<Callout>
  In the **desktop app (Tauri)**, everything is stored locally on your machine — nothing leaves it unless you explicitly export or sync.
</Callout>
