Every request you send is automatically saved to the **History panel**, accessible from a drawer on the right side of the header.

## Search & filters

The history panel includes powerful search and filtering tools:

- **Text search** by name, URL, method, or status code
- **Method chips** to filter by HTTP method (multi-select)
- **Status ranges** — quick filters for `2xx`, `4xx`, `5xx`, and errors

All filters compose together — text + method + status. A **Clear** button resets everything at once.

## Replay & follow-up

Each history entry offers two actions:

- **Replay** — reopen the request in the editor
- **AI Follow-Up** — generate a related request using AI (see [AI Integration](/docs/ai))

## Saving to collections

If you find yourself replaying a request regularly, save it into a [collection](/docs/collections) so it lives alongside the rest of your test suite.
